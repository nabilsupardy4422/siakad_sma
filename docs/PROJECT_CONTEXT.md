PROJECT: SIAKAD SMA

DESKRIPSI
Sistem Informasi Akademik Sekolah Menengah Atas berbasis web.

TUJUAN
Membantu sekolah dalam mengelola dan menyampaikan informasi
yang berkaitan dengan kegiatan akademik secara lebih teratur
dan mudah diakses.

FOKUS SISTEM
Pelaksanaan dan Evaluasi Kegiatan Belajar Mengajar (KBM).

AKTOR
1. Tata Usaha (TU)
2. Wakil Kepala Sekolah Bidang Kurikulum (Wakakur)
3. Guru Mata Pelajaran
4. Wali Kelas
5. Siswa

STACK TEKNOLOGI
Frontend  : React
Backend   : Laravel REST API
Database  : MySQL
Version Control : Git + GitHub

ARSITEKTUR
React
   ↓
Laravel REST API
   ↓
MySQL

ATURAN PROJECT
1. Fitur harus berdasarkan requirement.
2. Fitur di luar MVP tidak boleh dibuat tanpa persetujuan tim.
3. Struktur database harus mengikuti ERD.
4. Frontend tidak mengakses database secara langsung.
5. React berkomunikasi dengan backend melalui REST API.
6. Hak akses harus mengikuti role yang telah ditentukan.
7. Perubahan requirement harus disepakati tim terlebih dahulu.

STATUS
Dokumen ini merupakan baseline SIMULASI.
Requirement final harus divalidasi melalui wawancara
dengan pihak sekolah.
