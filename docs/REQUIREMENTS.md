FUNCTIONAL REQUIREMENTS

FR-001
Sistem menyediakan autentikasi pengguna.

FR-002
Sistem memberikan hak akses berdasarkan role pengguna.

FR-003
TU dapat mengelola data akademik dasar.

FR-004
TU dapat mengelola jadwal pelajaran.

FR-005
Wakakur dapat memvalidasi jadwal pelajaran.

FR-006
Guru dapat melihat jadwal mengajar.

FR-007
Guru dapat melihat daftar siswa berdasarkan kelas yang diajar.

FR-008
Guru dapat melakukan presensi siswa.

FR-009
Guru dapat menginput nilai siswa.

FR-010
Wali Kelas dapat melihat rekap presensi siswa.

FR-011
Wali Kelas dapat melihat rekap nilai siswa.

FR-012
Wali Kelas dapat memvalidasi data akademik kelas.

FR-013
Siswa dapat melihat jadwal.

FR-014
Siswa dapat melihat riwayat presensi.

FR-015
Siswa dapat melihat nilai.

FR-016
Sistem dapat menampilkan rekap akademik.


NON-FUNCTIONAL REQUIREMENTS

NFR-001
Sistem berbasis web.

NFR-002
Sistem menerapkan autentikasi pengguna.

NFR-003
Sistem menerapkan pembatasan hak akses berdasarkan role.

NFR-004
Antarmuka dapat digunakan melalui desktop dan perangkat mobile.

NFR-005
Data akademik hanya dapat diakses sesuai hak pengguna.
